# HTML cold pre-test before any reading

The learner had not read the MDN pages, so the HTML block started with a cold typed pre-test of seven questions (syntax, attributes, doctype, page structure, head contents, headings, whitespace). Roughly 4.5 of 7 correct.

## Evidence
- Correct: attributes (`name="value"` on the opening tag, with a correct `href` example), `<html>` with `<head>` and `<body>`, head contents (scripts, stylesheets, title), whitespace collapsing, `<br>` for a line break.
- Partly right: element vs tag (idea right, wording loose), the doctype ("standards mode" came only after a prompt), headings (accessibility named, but not outline, screen reader navigation or skipped levels).
- Missed: `lang` on `<html>`, `<meta charset>`, the viewport meta, and which of these are required.
- After a prompt the learner named void elements correctly.

## Decision
Enrich after targeted reading: skip the full three pages. Read the anatomy, void elements and attributes in Basic HTML syntax; the doctype, `lang`, head contents and landmarks in Structuring documents; the headings section of Headings and paragraphs. Then the diagnostic proper.

Re-test: on or after 2026-11-24.
