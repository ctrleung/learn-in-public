# Basic HTML syntax: read, then quizzed on the five learning outcomes

After the MDN page *Basic HTML syntax*, the learner was quizzed from memory on its five learning outcomes, in applied forms.

## Evidence
- **Anatomy of an element:** correct. Named the opening tag, content, closing tag and attributes of an `<a>` element, and said a tag is only part of an element. Precision: attributes are name and value pairs, and it is the pair of tags that encloses the content.
- **Correct nesting:** correct. Saw that the closing `strong` tag must come before the closing `p`.
- **Void elements:** correct on the name, but first said only that `p` has a closing tag; added that a void element has no content and no closing tag and gets its data from attributes.
- **The `body`:** correct. It holds the content shown on the page.
- **The doctype:** right on its current role (standards mode, not quirks mode) but missed its original purpose (a link to the rules for the HTML version, so tools could check the page). Partly right.
