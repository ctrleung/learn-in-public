# Anki cards

Importable card files for terms, generated from the glossary after lessons. One fact per card, Basic note type (Front, Back), with a tag column.

- `networking-terms.txt`: 15 networking terms from lesson 1, with the definition and its source on the back. The wording follows the sources; rewrite a card in your own words if that helps you remember it.

To import in Anki on a computer: File, then Import, then pick the file. I haven't checked the import steps for the Anki mobile apps; if it's awkward on your phone, import on a computer and sync.
