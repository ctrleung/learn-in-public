# korean

A notebook, not a study workspace. I'm learning Korean with Anki cards and I don't do lessons here. This folder keeps the memory aids that come out of asking Claude about words: the characters behind a word, and how it looks or sounds in other languages.

- `words.md`: one row per word I asked about, with the characters behind it, how it appears in Japanese, Mandarin and Cantonese, and my own memory aid.

## How it works

- While doing my cards, I ask about a word. Claude explains it and adds a row to `words.md`.
- The "My memory aid" column is for my own words, not Claude's.
- Anki keeps the schedule. Nothing here is tested or reviewed on a timer.
- Shared characters are worth noticing, because many Korean words come from Chinese characters (Hanja), and the same characters show up in Japanese kanji.
- This repo is public, so keep personal details out of these notes.
