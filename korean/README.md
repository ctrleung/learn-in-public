# korean

A notebook, not a study workspace. I'm learning Korean with Anki cards and I don't do lessons here. This folder keeps the memory aids that come out of asking Claude about words, mainly how a word sounds in other languages (Japanese, Cantonese, Mandarin), so I can remember it more easily.

- `words.md`: one row per word I asked about, with how it sounds in other languages, a note on which is closest, my own memory aid, and the characters as an optional extra.

## How it works

- While doing my cards, I ask about a word. Claude explains it and adds a row to `words.md`.
- The "My memory aid" column is for my own words, not Claude's.
- Anki keeps the schedule. Nothing here is tested or reviewed on a timer.
- Sound matches only exist for words that come from Chinese. Native Korean words have none, and Claude says so.
- This repo is public, so keep personal details out of these notes.
