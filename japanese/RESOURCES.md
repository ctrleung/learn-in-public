# Japanese Resources

> These are the learner's own materials. They have not been read or checked by Claude; lessons should follow what the learner is actually working through, and cite a page or chapter only after the learner shares it.

## Knowledge

- **Genki textbook.** The main course book. Use for: grammar and vocabulary in the order the learner is studying them. Ask which chapter the learner is on before building a lesson.
- **Genki workbook.** The practice companion to the textbook. Use for: the learner's own exercises; test on what they've already done there.
- **Genki app.** Used for audio. Use for: listening and pronunciation, which typed chat quizzes can't cover.
- **Anki.** Vocabulary flashcards, outside this repo. Word lists can live here if the learner wants them versioned.
- **Renshuu.** Where the learner is learning hiragana, outside this repo.
