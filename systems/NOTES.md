# Notes

## Learner

- Working programmer, mainly frontend, some backend and API experience. Wants to keep hand-coding skills sharp.

## Preferences

- Short sessions; uneven weekly energy.
- Wants durable, referable notes that others can read too (repo is public). Keep personal details out of committed files.
- Security thread: ask "how does this get attacked, and how is it mitigated?"

## How to teach me

- Quiz before explaining: ask typed questions first, then teach. Not multiple choice.
- Don't hand me finished answers. Give a hint or a narrower question and let me try again; explain only after a real attempt.
- Everything I miss goes in `gaps.md`. I write the fix in my own words; it becomes fixed only after I answer correctly from memory on a re-test.

## Session routine

- Same as `../web/NOTES.md`: warm-up from due re-tests and open gaps, explain-back at the end, a learning record ending with "Re-test: on or after <date>", a log line tagged `[systems]`, a branch and a PR.
