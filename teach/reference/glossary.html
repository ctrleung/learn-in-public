Networking glossary

Terms used across lessons. Each definition follows the cited source; lessons must use these terms the same way.

Client
An internet-connected device, plus the web-accessing software on it (usually a browser). MDN
Server
A computer that stores webpages, sites or apps. MDN
URL
Defines the location of a unique resource on the internet. Main parts: protocol (https), domain name, optional subdomain, and path. MDN
IP address
A number such as 192.0.2.172 that represents a unique location on the web. MDN
DNS (Domain Name System)
Special servers that match the web address you type to the website's real IP address, like an address book. The browser needs this before it can retrieve the site. MDN
TCP/IP
Communication protocols that define how data should travel across the internet. MDN
Packet
A small chunk of data sent between client and server. It has a header (client and server IP addresses, packet number, total packets, protocol details) and a payload (the actual data). MDN
HTTP
An application protocol: the language clients and servers use to talk to each other. MDN
HTTP status code
Part of the response saying whether the request worked. Common ones: 200 success; 301 permanently moved; 400 server can't process the request; 403 server won't give access; 404 server can't find it; 503 server can't handle it right now (temporary). MDN
HTTPS
A secure version of HTTP that stops bad people from reading your data while it is being transported. MDN
TLS (Transport Layer Security)
A protocol designed to give applications running above it three services: encryption, authentication and data integrity. HPBN
Encryption
A mechanism to obfuscate what is sent from one host to another. HPBN
Authentication
A mechanism to verify the validity of provided identification material. In the browser, it lets the client check the server is who it claims to be and not someone pretending to be the destination by spoofing its name or IP address. HPBN
Integrity
A mechanism to detect message tampering and forgery. TLS signs each message with a message authentication code (MAC), a one-way cryptographic hash (effectively a checksum). HPBN
Public key cryptography
Lets two peers negotiate a shared secret key without prior knowledge of each other, over an unencrypted channel. This is why TLS works in practice. HPBN
